## 它能做什么

```
游戏里  #你好            →  QQ 群里出现「你的游戏名: 你好」
游戏里  #@某人 你好       →  QQ 里真的 @ 到他（会弹红点那种）
游戏里  *你好            →  AI 回复，聊天栏出现 [AI] 你好
QQ 里   #你好            →  游戏聊天栏出现 [QQ] 昵称: 你好
```

- **双向**：游戏 → QQ、QQ → 游戏，两个方向都能用
- **真 @ 人**：游戏里 `#@昵称` 或 `#@QQ号`，QQ 群里是**真的 @**（不是文字）
- **游戏内 AI 对话**：`*文本` 直接问，用的是你 AstrBot 里配的模型 + 人格，**有上下文记忆**
- **本地直连，不用公网**：游戏和 AstrBot 在同一台电脑上，走 `127.0.0.1`，不经过中转
- **断线自动重连**、掉线期间的消息会补发

## 需要的另一半：游戏侧模组

这个插件只负责「外部那一半」。游戏里那一半是一个**中国版 ModSDK 模组**（行为包）：

| | |
| --- | --- |
| 名字 | **群服互通** |
| 获取 | 在模组发布页 / 群文件下载后，用 MC Studio 导入（或把行为包放进存档） |
| 为什么需要 | 中国版删掉了 WebSocket 接口，得靠模组自己用 socket 实现 —— 模组里内置了手写的 RFC 6455 客户端 |

模组默认连的就是 `ws://127.0.0.1:8800/`（也就是本插件），所以**两边都装好、游戏里敲 `#连接` 就通**。

> 没有模组也能用这个插件：任何会连 `ws://127.0.0.1:8800/` 的客户端都行（自己写一个也行）。

## 安装

### 方式一：让 AstrBot 从仓库装（推荐）

AstrBot WebUI → 插件 → 安装插件 → 填本仓库地址：

```
https://github.com/mufenga-mc/astrbot_plugin_neteasemc
```

> AstrBot 要求 **`metadata.yaml` 在仓库根目录**（不是套一层文件夹），本仓库就是这个结构。

### 方式二：手动放

把本仓库整个文件夹放进 AstrBot 的 `data/plugins/astrbot_plugin_neteasemc/`，
然后在 WebUI 里重载插件（或重启 AstrBot）。

装好后 AstrBot 日志里应该出现：

```
[mc-bridge] WebSocket 服务端已启动：ws://127.0.0.1:8800/
```

### 装完必须做一步：绑定会话

在你想收游戏消息的 QQ 群（或私聊）里发：

```
/mc bind
```

**这步不做，游戏消息不会进 QQ。** 绑定关系存在插件数据目录里，所以**重装插件、换插件名之后要重新 `/mc bind`**。

## 快速开始

1. 装好插件 → `/mc bind`
2. 装好模组 → 进存档 → 聊天栏敲 `#连接`
3. 游戏里发 `#你好` → QQ 群里应该出现「你的游戏名: 你好」
4. QQ 里发 `#你好` → 游戏聊天栏应该出现 `[QQ] 昵称: 你好`

## 指令

### 游戏里（由模组负责，插件只是接收）

| 指令 | 作用 |
| --- | --- |
| `#连接 [编号\|地址]` | 连上插件。不写 = 用目标文件那条；写数字 = 第 N 条；写地址 = 直接连（`#连接 127.0.0.1:8800`） |
| `#文本` | 发给 QQ —— `#` 后面直接写内容（会自动带上「谁说的」） |
| `*文本` | 和 AI 对话，回复以 `[AI]` 开头 |
| `#@某人 文本` | 在 QQ 里真的 @ 他 |
| `#状态` / `#断开` / `#帮助` | 看状态 / 断开 / 全部说明 |

### QQ 里

| 指令 | 作用 |
| --- | --- |
| `/mc bind` | 把当前会话设为转发目标（**必做一次**） |
| `/mc status` | 看桥的状态：游戏连没连上、目标会话、AI 模型、群成员缓存 |
| `/mc persona` | 看 / 列出可用人设 |
| `/mc forget` | 清空游戏 AI 的记忆 |
| `/mc send 文本` | 手动推一条给游戏 |
| `/mc help` | 帮助 |
| `#文本` | 直接发消息给游戏（前缀可在配置里改） |

> QQ 里 **@机器人 不算触发** —— `@机器人 你好` 是和机器人正常聊天，要转发得带 `#`，即 `@机器人 #你好`。
> 这样群里聊天和桥互不打扰。

## @ 人的用法

| 写法 | 说明 |
| --- | --- |
| `#@123456789 你好` | 按 QQ 号 @（**不查列表，最快最稳**） |
| `#@昵称 你好` | 按群昵称 / 群名片 @（会查群成员列表，缓存 60 秒） |
| `#@全体成员 集合` | @全体成员 |
| `#@A @B 你们好` | 连着 @ 好几个 |

认不出来的名字不会让整条消息丢掉：那个 `@` 会退化成纯文本，并在群里附一句「（没找到群成员：xxx）」。

> 按昵称 @ 需要知道群号和机器人句柄 —— 这两个是**从绑定会话里解析**的，所以只要 `/mc bind` 过就能用，
> 不必等群里先来一条消息。

## 和 AI 对话

游戏里 `*你好` → 插件调用 **AstrBot 当前使用的对话模型**，把回复推回游戏：

```
游戏里： *今天天气怎么样
游戏里： [AI] 我看不到窗外，但你那边要是晴天，记得别在正午锄地
```

- **走的是你 AstrBot 里配的模型**，不用另外配 key；
- **有上下文记忆**：默认记 6 轮（`ai_history_rounds` 可调，`0` = 不记），存盘，重启不失忆，`/mc forget` 清空；
- 回复**只发到游戏**，不会回到 QQ；
- 多行回复会拆成多条推；模组会自动折行，长回复不会被截断。

### 人设怎么自定义

三种方式，**从上往下优先级递减**：

| 想干什么 | 怎么配 |
| --- | --- |
| 给游戏这路单独写一段人设 | 配置 `ai_system_prompt`（**填了就它说话**） |
| 复用 AstrBot 里已写好的人格 | 先 `/mc persona` 看有哪些，再把名字填进 `ai_persona` |
| 跟 QQ 那边用同一套 | 什么都不填（默认取 AstrBot 的默认人格） |
| 不要人设（裸模型） | `ai_use_default_persona` 关掉，且上面两个留空 |

> ⚠️ 直接调 `provider.text_chat()` 是**绕过 AstrBot 对话管线**的，WebUI 里配的人格不会自动生效 ——
> 所以插件自己把人格取出来塞进 `system_prompt`。不填的话，模型就是「没有灵魂的裸模型」。

例子（`ai_system_prompt`）：

```
你是一只住在《我的世界》里的猫，说话短、爱吐槽，偶尔用颜文字。
玩家在游戏里跟你聊天，回答要口语化，别超过三句话。
```

## 配置项（WebUI 插件配置页）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `host` | `127.0.0.1` | 监听地址。想让**局域网**（手机 / 别的电脑）也能连就改 `0.0.0.0` |
| `port` | `8800` | WebSocket 监听端口（要和游戏侧目标文件里那条一致） |
| `token` | 空 | 连接口令；填了之后游戏侧地址要带 `?token=xxx`。**对外网开放时必填** |
| `target_session` | 空 | 目标会话；一般用 `/mc bind` 自动填 |
| `forward_game_to_qq` | 开 | 游戏 → QQ |
| `forward_qq_to_game` | 开 | QQ → 游戏 |
| `qq_prefix` | `#` | 只有以此开头的 QQ 消息才推给游戏（留空 = 全部，慎用） |
| `name_prefix` | 开 | 推给游戏时带上发送者昵称 |
| `game_prefix` | `[QQ] ` | 推给游戏时加的前缀 |
| `at_resolve` | 开 | 游戏里 `@昵称` 时去查群成员列表解析成真 @（关掉则只支持 `@QQ号`） |
| `ai_prefix` | `*` | 游戏里以它开头就是「和 AI 对话」 |
| `ai_label` | `[AI] ` | AI 回复的前缀 |
| `ai_history_rounds` | 6 | 记住最近几轮问答（`0` = 不记） |
| `ai_system_prompt` | 空 | 游戏这路 AI 的人设（优先级最高） |
| `ai_persona` | 空 | 用 AstrBot 里的哪个人格 |
| `ai_use_default_persona` | 开 | 没指定人格时用 AstrBot 默认人格 |
| `ai_thinking_notice` | 关 | 模型慢时先推一句「（在想…）」 |

> 转发**成功不吭声**（游戏那边聊天栏会出现这条消息），**只有失败才回一句**提示 —— 免得群里刷屏。

## 排查

- **游戏里出现 `[桥] …`**：插件把「转发失败」的原因回传到游戏聊天栏了（以前只写 AstrBot 控制台，
  玩游戏的人看不到，症状就是「发了消息 QQ 没反应」）：
  - `[桥] 还没绑定 QQ 会话` → 在群里发一次 `/mc bind`；
  - `[桥] 转发到 QQ 失败/出错` → 机器人可能掉线了，群里发 `/mc status` 看看。

- **游戏连不上**：
  - AstrBot 那边看日志有没有 `WebSocket 服务端已启动`；没有的话大概是**端口被占用**；
  - 游戏侧 `#状态` 看状态；连不上时聊天栏会给「人话 + 例子」。

- **游戏消息没进 QQ**：多半是还没 `/mc bind`；`/mc status` 能看到「目标会话」是不是空的。

- **QQ 消息没进游戏**：检查 `qq_prefix`（只有以它开头的消息才会被转发）；
  另外 `/mc status` 里「游戏连接」要是「未接入」，就是游戏没连上。

- **`@昵称` 没变成真的 @**：`/mc status` 看「群成员缓存：N 人」——
  `0 人` = 拿不到列表（机器人不在群里 / 权限不足），这时用 `#@QQ号` 或 `#@全体成员` 最稳。

## 离线自测

不需要游戏、也不需要启动 AstrBot：

```powershell
<实例目录>\venv\Scripts\python.exe tests\test_link.py
<实例目录>\venv\Scripts\python.exe tests\test_mentions.py
<实例目录>\venv\Scripts\python.exe tests\test_ai.py
<实例目录>\venv\Scripts\python.exe tests\test_bridge.py
```

四个加起来 **47 项检查**，拿的都是真代码配假依赖（不是复制一份逻辑）：

| 文件 | 覆盖 |
| --- | --- |
| `test_link.py` | 基本收发 / 第二个连接踢旧连接 / 断开状态 / token 校验（403） |
| `test_mentions.py` | @ 解析：按昵称、按 QQ 号、@全体、找不到、说话人前缀剥离 |
| `test_ai.py` | AI 那一路：多行拆分、人设优先级、记忆与上限、各种出错分支 |
| `test_bridge.py` | 游戏→QQ：正常转发 + 三种失败都要在游戏里可见；`@` 不被说话人前缀挡住 |

> 用 **AstrBot 那个 venv 的 python** 跑（`test_link.py` 要 aiohttp）。
> `test_mentions.py` / `test_ai.py` / `test_bridge.py` 还要能 import `astrbot` ——
> **venv 里其实没装这个包**，所以 `tests/_bootstrap.py` 会自动去找 AstrBot 的 `core` 目录
> （顺序：环境变量 `ASTRBOT_CORE` → 当前目录往上找 → `~/.astrbot_launcher/instances/*/core`）。

## 工作原理（想改代码的话）

```
游戏（模组）  --ws://127.0.0.1:8800-->  本插件  -->  AstrBot --> QQ
     ↑                                      |
     └────────── 推回去的文本 ───────────────┘
```

- 插件用 **aiohttp** 起一个本地 WebSocket 服务端（`mc_ws_server.py`，可离线测试）；
- 游戏侧是手写的 RFC 6455 客户端（因为中国版沙箱里既没有 websocket 库、也没有 `ssl`）；
- **协议就是纯文本帧**：游戏发什么，插件就当什么处理。没有自定义封装，所以任何一个能连上来的客户端都能用。

## 已知限制

- **游戏和 AstrBot 必须在同一台电脑上**（默认连 `127.0.0.1`）。想让手机版玩家连你的电脑，
  把 `host` 改成 `0.0.0.0`，游戏侧连你的局域网 IP；
- **同时只接受 1 条游戏连接** —— 新的会踢掉旧的（多人共用一个桥的话要注意）；
- 明文 `ws://` **不加密**（`token` 只能防乱连，不防窃听）。要跨公网建议只在自己内网用；
- 只用 `aiocqhttp`（QQ）平台测过（`metadata.yaml` 里也只声明了它）。
